# Walmart Sales Analysis Using Excel

## Project Overview
Analyzed Walmart sales data using Excel to evaluate sales performance, profitability, and customer purchasing patterns. Developed an Excel dashboard to present key performance indicators and explore trends across product categories, regions, and months.

## Tools Used
- Microsoft Excel / WPS Spreadsheets
- Excel Formulas and Functions
- PivotTables and Pivot Charts
- KPI Analysis
- Data Visualization

## Key Features
- **Sales and Profit Analysis:** Evaluated total sales, profit, quantity sold, and average performance.
- **Category Analysis:** Compared sales, profit, and quantity across product categories.
- **Regional Analysis:** Examined performance across different regions, cities, and states.
- **Monthly Trend Analysis:** Analyzed sales and profit patterns throughout the year.
- **Customer Analysis:** Explored customer types, payment methods, and customer ratings.
- **Profitability Analysis:** Examined profit margins, discounts, and target margin performance.
- **Dashboard:** Presented key metrics and analysis through charts and visualizations.

## Key Insights
- Electronics generated the highest sales and profit among the product categories.
- Grocery recorded the lowest sales among the categories.
- The South region generated the highest revenue.
- June recorded the lowest monthly sales in the analysis.

## Skills Demonstrated
- Data cleaning and feature engineering
- Excel formulas and conditional functions
- Data summarization using PivotTables
- Sales and profitability analysis
- Dashboard development and data visualization
- Business insight generation


## Conclusion
This project demonstrates how Excel can be used to analyze sales data, monitor business performance, identify trends, and generate insights to support data-driven decisions.
